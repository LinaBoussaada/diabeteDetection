🧠 Mini-Projet : Analyse & Fouille de Données (ML)
Projet de data science combinant exploration de données, machine learning supervisé/non supervisé, et interface graphique interactive.

🚀 Objectifs
💾 Prétraitement d’un dataset médical réel (diabète)

🤖 Modélisation ML : classification (Random Forest, Logistic Regression...), clustering (K-Means, DBSCAN...)

📊 Visualisation des résultats

🖥️ Interface interactive (Streamlit)

📂 Dataset utilisé
Diabetes Dataset (CSV)
Variables : Grossesses, Glucose, Pression artérielle, IMC, Âge, etc.
Cible : Outcome (0 = non diabétique, 1 = diabétique)

🧰 Livrables
Code Python (Notebook + script)

Interface graphique (Streamlit) via link : https://jpqjbwzybzedjprx5ay2th.streamlit.app/
